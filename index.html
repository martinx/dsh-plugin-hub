消息时间戳常显

v0.1.0

Chat Clock

让 DSH 聊天里的消息时间戳不再依赖鼠标悬停，旧消息也能一眼看到发送时间。

界面 timestampchatui 
git clone git@github.com:martinx/dsh-chat-clock.git
cd dsh-chat-clock
bash install.sh

纯样式型客户端插件，不改 DSH 源码；每个思考/工具调用的独立时间仍需核心改动。

GitHub ↗ README 版本

工作区 Git/PR 状态

v0.3.2

Workspace Status

输入框下方 dock 行首的状态栏：显示路径、分支/tag、变更、项目环境；GitHub 分支可创建/查看 PR 与 Actions 检查。没有的条目自动隐藏，非 git 目录也显示路径与环境。

开发 gitgithubpull-requestdiffbranchstatus 
git clone git@github.com:martinx/dsh-workspace-status.git
cd dsh-workspace-status
bash install.sh

需要 git；PR/检查状态需要 gh 已登录；宿主代码更新后需重启 DSH；切换分支在脏工作区可能失败。

在 DSH 里添加市场

添加索引源后，插件页的 Discover 会列出全部插件与版本，可直接安装。

1
打开插件页DSH → 插件 → 更多 → 实验性插件
2
打开自定义插件市场开启「Custom plugin markets」
3
添加索引源粘贴右侧地址，确认后进入 Discover

插件市场索引

把这个地址加到 DSH 的插件市场索引源：

https://plugins.bitey.ai/market.json

或者直接克隆仓库，手动运行 install.sh 安装单个插件。
