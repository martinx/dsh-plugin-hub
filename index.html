消息时间戳常显

v0.1.0

Chat Clock

让 DSH 聊天里的消息时间戳不再依赖鼠标悬停，旧消息也能一眼看到发送时间。

Keep message timestamps always visible in the DSH chat, including older messages.

界面 timestampchatui 
git clone git@github.com:martinx/dsh-chat-clock.git
cd dsh-chat-clock
bash install.sh

纯样式型客户端插件，不改 DSH 源码；每个思考/工具调用的独立时间仍需核心改动。

工作区 Git/PR 状态

v0.1.1

Workspace Status

在输入框下方的 composer dock 显示当前仓库的分支、暂存/未暂存/未跟踪/冲突数量、ahead/behind，以及 GitHub PR 状态，点击可直接打开 PR。

A composer-dock pill showing the current repo's branch, staged/unstaged/untracked/conflicted counts, ahead/behind, and the GitHub PR status (click to open).

开发 gitgithubpull-requeststatus 
git clone git@github.com:martinx/dsh-workspace-status.git
cd dsh-workspace-status
bash install.sh

需要本机有 git；PR 状态需要 gh 已登录；非 git 目录自动隐藏；15 秒轮询。
